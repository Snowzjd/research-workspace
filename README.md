# 科研工程工作台 4.0.0

面向个人科研的 Windows x64 桌面工作台。可管理项目、任务、材料与成果，在本机阅读和编辑 Markdown，按科研关系、文件归属或笔记引用探索知识图谱。

从 [正式发布页](../../releases/tag/v4.0.0) 下载 `ResearchWorkspace-4.0.0-Windows-x64.zip`。核对 SHA-256，解压到新目录后运行 `start.cmd`。旧版与正式版可以并排保留。
